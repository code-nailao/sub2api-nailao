# 保留能力的逐项验收场景

本表防止“名字一样，能力少了一半”。每个保留能力列出必须覆盖的场景；改动相关能力或同步原版时，按受影响的行回归。范围说明见 [EXTENSIONS](EXTENSIONS.md)，现行能力见 [SOURCES](../../SOURCES.md)。

各场景的执行结果属于具体某次发布的验收记录，不写在本表中。记录结果时遵守：通过必须有对应的真实证据；合成数据、模拟上游和真实数据分开说明；没有运行或失败的项不记为通过。

## 工作台客户端测试

独立工作台客户端在自己的仓库中用模拟上游测试协议与状态机，不触发真实生成或扣费：

```sh
npm test -- src/lib/sub2apiImageTasks.test.ts src/lib/taskState.test.ts src/lib/api.test.ts
npm run build
npm test
```

这些测试锁定客户端协议，不代替与原版、S3 或媒体引擎的真实联调。

## 完成判据

每个保留项需要记录：旧实现来源、新实现位置、必要配置、成功与失败测试、截图/响应/计费证据和回退路径。任何发布必需的场景未通过时，相应能力不能视为完成。
